# Harvestly – Farmer-to-Buyer Marketplace

Harvestly is a web-based platform designed to connect farmers directly with buyers, making agricultural product trading easier, more accessible, and efficient.

## Features

- Farmer and buyer user accounts
- User authentication
- Agricultural product listings
- Product browsing and management
- Buyer and farmer dashboards
- Order and delivery management
- Admin management

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Installation Guide

1. Install XAMPP.
2. Clone or download this repository.
3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL using XAMPP.
5. Create a MySQL database using the provided database files.
6. Configure the database connection in the `config` directory.
7. Open the project in your browser using the appropriate localhost project path.

## Database Setup

Import the provided SQL database file using phpMyAdmin and configure the database credentials before running the application.
